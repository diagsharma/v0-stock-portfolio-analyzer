01

Purpose

New investors read stock picks on Reddit and TikTok with no historical context for whether any of it would have worked. The tools that would tell them cost $12,000–$24,000 a year and are built for institutions. The alternative is downloading CSVs from Yahoo and attempting spreadsheet formulas they do not yet understand.

This app closes that gap. Enter up to ten tickers and a date range; it fetches real daily prices, computes the four metrics that matter, and plots the result against the S&P 500 so the comparison is unavoidable rather than implied.

The design constraint that shaped everything: a wrong answer is worse than no answer. Someone deciding where to put their first $1,000 is better served by an error message than by a confident number that happens to be false. Much of the engineering below exists to honour that.

02

Approach

The project arrived behind schedule with a partly-built v0 scaffold: a good-looking UI, a metrics function, and a backend that had never successfully completed a single run. Work was re-sequenced by grade weight per hour rather than by the original week order, so the highest-value, least-blocked work landed first.

Constraint discovered mid-build

The specification named Alpha Vantage as the data source. By the time the project ran, its free tier had moved outputsize=full behind a paywall — capping daily history at the most recent 100 trading days. No multi-year backtest was possible. This was the actual reason every previous production run had failed. It forced the provider abstraction described next.

04

The bug that inverted the answer

A user reported an intermittent fetch failure on two ETFs. The crash was real and easily fixed. Underneath it sat something worse, and silent.

GPIQ listed in October 2023. Asked for a five-year backtest, the app started the portfolio at the fund's inception — correctly — but kept measuring the S&P 500 across the full five years. It then compared the two numbers as though they described the same period.

For a second fund, JEPQ, the correction reversed the verdict outright: from “beat the market by 5 points” to lagging it by 0.8. The app had been confidently telling users the opposite of the truth.

Why it matters beyond this project

The crash announced itself. This did not — it produced a plausible number in a well-designed card, and only surfaced because a real user tried a real portfolio the five canned test scenarios never covered. Test data drawn from mature large-caps cannot catch a bug whose trigger is a short price history.

05

What the architecture buys

Survives its own data source

When Alpha Vantage paywalled multi-year history, only one file needed to change behaviour. The provider interface meant the outage became a fallback rather than an outage.

1 file, not a rewrite

Arithmetic can only be wrong once

Every metric lives in framework-free CommonJS shared by both entry points, with no I/O anywhere in it. That is also why it is fast and cheap to test.

91 tests, zero network calls

Failures are typed, not guessed

Each error carries the status it deserves, so an unknown ticker returns 400 with a usable message while a provider outage returns 502 — no string-matching in route handlers.

400 vs 502, never a blanket 500

Honest about its own limits

When a holding shortens the window, the dashboard says so. The alternative — silently adjusting — is how the original bug stayed invisible.

Stated, not hidden

Fast enough to feel instant

Bounded parallel fetching plus a session cache: ten tickers over five years resolve well inside the ten-second budget, and a repeat request is served from memory.

637ms for 10 · 1ms cached

Runs with nothing configured

No database required, no API key required. Persistence and the primary provider are both enhancements, so a fresh clone works immediately.

Zero mandatory credentials
